Project Description

Inspired by my first PCB and a curiosity to experiment with generative 3D models, this project investigates the boundary between generation and accuracy in digital reconstruction.

I built a web platform that allows users to upload GLB files and autopsy 3D models directly in the browser, enabling close inspection of their structure, geometry, and artifacts. The tool serves both as a technical experiment and as a way to study how generative AI and scanned data diverge from physical reality.

The project combines AI-generated geometry, photogrammetry scans, and traditional 3D pipelines to explore how these different methods construct digital representations of the same object.
